# バトオペ2 カスタムパーツ仮組みツール

『機動戦士ガンダム バトルオペレーション2』のカスタムパーツ構成を、ブラウザ上で試算できる非公式Webツールです。

## 主な機能

- カスタムパーツの装備・解除
- 装備スロットの自動計算
- 機体ステータスの自動計算
- 火力指数・耐久指数の計算
- カスタムパーツ構成の自動最適化
- 構成の保存・読み込み・比較
- PC・スマートフォン対応

## 使い方

1. HTMLファイルをブラウザで開きます。
2. 機体の基礎ステータスとスロット数を入力します。
3. 使用するカスタムパーツを選択します。
4. 装備後のステータスや各種指数が自動で計算されます。

## 動作環境

JavaScriptが有効なWebブラウザで動作します。

- Google Chrome
- Microsoft Edge
- Firefox
- Safari

## 注意事項

- 本ツールは非公式のファンメイドツールです。
- ゲーム内の実際の計算結果と異なる場合があります。
- ゲームのアップデートにより、パーツ性能などが変更される場合があります。
